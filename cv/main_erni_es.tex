\item \textbf{AIDucate} -- \textit{Go, Gin, PostgreSQL, React, TypeScript, Tailwind, API de Gemini}: Plataforma SaaS full-stack que genera planes de estudio, contenido y ejercicios personalizados. API REST en Go/Gin con autenticación JWT, persistencia en PostgreSQL e integración con la API de Gemini; frontend en React/TypeScript desplegado en Vercel, backend en Render. \textit{(En desarrollo)}

\item \textbf{FaaS con Golang} -- \textit{Go, Docker, NATS JetStream, Apache APISIX}: Plataforma distribuida de Function-as-a-Service (serverless) en la que workers en Go ejecutan funciones arbitrarias empaquetadas en imágenes Docker. Colas de trabajo con NATS JetStream para una distribución de tareas fiable y orientada a eventos, gateway con Apache APISIX para autenticación JWT y limitación de tasa, y escalado horizontal mediante réplicas de Docker Compose.

\item \textbf{Plataforma de Venta de Entradas con Kafka y Spring Boot} -- \textit{Java, Spring Boot 3, Apache Kafka, Testcontainers}: Microservicios orientados a eventos (reserva, pago, notificación, auditoría) con patrón outbox, colas de mensajes fallidos (dead-letter), procesamiento idempotente y pruebas de integración con Testcontainers.

\item \textbf{CleanApp} -- \textit{React 19, TypeScript, Vite, Firebase}: Aplicación gamificada de reparto de tareas domésticas entre compañeros de piso, con base de datos en tiempo real y autenticación de Firebase, rotación algorítmica de tareas y sistema de puntos y clasificación.

\item \textbf{OAuth RSE} -- \textit{Python, Flask, Docker, OAuth 2.0}: Gestor de tareas contenerizado con Docker que implementa el flujo OAuth 2.0 Authorization Code con integración de la API de Google Drive.

\end{itemize}
